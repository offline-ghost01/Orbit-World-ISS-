# ORBIT WORLD - 195 Country ISS Tracker

**Built 100% on phone in Harare, Zimbabwe - No PC, No WiFi, 100% Offline**

By **Tafadzwa Mushayabasa aka Jet Kross (offline-ghost01)**

### What is it?
Real-time ISS + CSS + Tianzhou tracker that works WITHOUT internet. Calculates when ISS flies over ANY of the 195 UN countries using real TLE data. 

Paste TLE once a month, then 100% offline forever.

### Features
- 195 Countries pre-loaded
- ISS, CSS, Tiangong orbits
- Pass predictions, elevation, azimuth
- Kivy UI, runs on Pydroid3 Android
- No API, No internet needed

### Tech
Python + Kivy + SGP4 math, TLE propagation

### Files
- `orbit_world_full.py` - main app
- `collage.jpg` - screenshots

### How to run
1. Install Pydroid3
2. pip install kivy
3. Run: python orbit_world_full.py

Built for Hack Club Athena - Proving you can build world-class space tech from Zimbabwe on a phone.
